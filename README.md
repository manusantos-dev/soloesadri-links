### 🎀 The Origin Story
Standard link-in-bio tools are boring. My friend is a musician with a very specific aesthetic. Instead of settling for a generic template or paying a premium subscription to change a background color, I decided to code her a bespoke web experience from scratch.

The goal was simple: capture the essence of a 2000s teen magazine (Preppy Y2K / Coquette), make it fully responsive, and most importantly, allow the user to update their own links in the future without having to call me or learn how to write HTML. 

> **🤖 Transparency Note (or "How I built this without losing my mind over CSS SVGs")**
> Just like my previous projects, this is the result of focused *vibe coding*. I provided the architectural decisions, set up the Netlify Identity/Git Gateway integrations, and acted as the Art Director demanding specific "purse brown" hex codes and non-spiky bows. My AI assistant handled the heavy syntax lifting and generated the custom SVG patterns by code. If you know what you want and how to ask for it, you can build a full-stack integrated site in a single afternoon.

---

## 💻 Technical Features

Built without heavy UI frameworks, focusing on crisp CSS3 design and a decoupled content management approach.

* **Headless CMS Integration (Decap CMS):** Integrated via Netlify Identity and Git Gateway. The client can access a private `/admin` dashboard to visually edit the bio, links, and avatar. 
* **Real-time Git Sync:** Every change made in the CMS automatically triggers a `git commit` to this repository, prompting Netlify to rebuild and deploy the site in seconds.
* **Preppy Y2K & Coquette UI:** A meticulously crafted aesthetic featuring a strict color palette (Carmine, Crisp White, Navy Blue, and Black), custom background patterns, and solid Y2K-era drop shadows.
* **Responsive Share Modal:** A custom-built JavaScript modal that perfectly mimics native share sheets, featuring native SVG icons to prevent ad-blocker or font-rendering issues.
* **The Poodle Easter Egg:** The site's favicon isn't just a generic icon. It's a custom-coded, 16x16 SVG pixel-art tribute to a beloved white poodle.

### 🎀 La verdadera historia
Las herramientas estándar de *link-in-bio* son aburridas. Mi amiga es música y tiene una estética muy específica. En lugar de conformarse con una plantilla genérica o pagar una suscripción mensual solo para cambiar un color de fondo, decidí programarle una experiencia web a medida desde cero.

El objetivo era claro: capturar la esencia de una revista adolescente de los 2000 (estética *Preppy Y2K / Coquette*), hacerla 100% *responsive*, y lo más importante, permitir al usuario actualizar sus propios enlaces en el futuro sin tener que llamarme ni aprender HTML.

> **🤖 Nota de transparencia (o "Cómo construí esto sin volverme loco con los SVGs en CSS")**

## 💻 Características Técnicas

Construido sin *frameworks* pesados de UI, apostando por un diseño CSS3 impecable y un enfoque de gestión de contenido desacoplado.

* **Integración CMS Headless (Decap CMS):** Conectado mediante Netlify Identity y Git Gateway. El cliente puede acceder a un panel privado `/admin` para editar visualmente su biografía, enlaces y foto de perfil.
* **Sincronización Git en Tiempo Real:** Cada cambio realizado en el panel de administración genera automáticamente un `git commit` en este repositorio, lo que indica a Netlify que debe recompilar y desplegar la web en segundos.
* **UI Estética Preppy Y2K & Coquette:** Un diseño meticulosamente elaborado con una paleta de colores estricta (Carmín, Blanco camisa, Azul Marino y Negro), patrones de fondo personalizados y sombras sólidas de la era Y2K.
* **Modal de Compartir Responsive:** Un modal creado en JavaScript puro que imita a la perfección los menús nativos de los móviles, utilizando iconos SVG incrustados para evitar problemas con bloqueadores de anuncios.
* **El "Easter Egg" del Caniche:** El *favicon* del sitio no es un icono genérico. Es un tributo programado en *pixel-art* SVG de 16x16 dedicado a un querido caniche blanco.
